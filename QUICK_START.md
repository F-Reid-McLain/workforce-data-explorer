# Quick Start Guide - Data Visualization Generator

## 🚀 Getting Started (For Marketing Team)

### Step 1: Open the Tool
Simply open `index.html` in your web browser. That's it - no installation needed!

### Step 2: Select Your Data
1. Click the **"Data Source"** dropdown
2. Choose from:
   - **Industry Snapshot** - Industry employment and demand data
   - **Occupation Snapshot** - Occupation-specific employment data
   - **Occupation Wages** - Wage and salary information

### Step 3: Pick Your Columns
The available columns will appear on the left. Check the boxes next to the metrics you want to visualize:
- By default, the first 2-3 columns are selected
- Uncheck unwanted columns
- **Tip:** Start with 2-3 columns max for a clean, readable chart

### Step 4: Choose Chart Type
Select how you want to display the data:
- 📊 **Bar Chart** - Best for comparing values across categories
- 📈 **Line Chart** - Best for showing trends over time
- 🥧 **Pie Chart** - Best for showing proportions of a whole
- 🍩 **Doughnut Chart** - Like pie, but with a center hole
- 📍 **Scatter Chart** - Best for showing relationships between two variables

### Step 5: Customize (Optional)
Make the chart yours:

**Chart Title**
- Add a descriptive title (e.g., "Top 10 Industries by Employment")

**Color Scheme**
- Choose a preset: Default, Vibrant, Pastel, or Muted
- Or pick "Custom Colors" to use your brand colors

**Display Options**
- ✓ Show Legend - Display the data series names
- ✓ Show Grid - Display background grid lines

**Max Rows to Display**
- Limit the number of rows shown (1-100)
- Default is 10 rows (top 10 results)

### Step 6: Download Your Chart
Choose your format:
- **PNG** - Quick sharing, social media, presentations
- **SVG** - Vector format, scales perfectly, can edit in Adobe software
- **PDF** - Print-ready, professional documents

All downloads have transparent backgrounds perfect for marketing materials.

## 💡 Pro Tips

### Making Great Charts

1. **Less is More**
   - Show 2-3 key metrics, not all columns
   - Shows top 10-20 rows, not the entire dataset
   - Use a descriptive, concise title

2. **Color Matters**
   - Use "Vibrant" for presentations and social media
   - Use "Muted" for professional reports
   - Use "Custom Colors" to match your brand

3. **Right Chart Type**
   - Bar: Comparing values
   - Line: Showing trends
   - Pie/Doughnut: Parts of a whole
   - Scatter: Relationships

4. **Before Exporting**
   - Make sure the chart looks good on screen
   - Check that all axis labels are readable
   - Verify the title accurately describes the data

## ❓ FAQ

**Q: How do I update the data?**
A: Data is updated quarterly. The developer will run a Python script to process new Excel files. You don't need to do anything - just use the tool as normal.

**Q: Can I use these charts in PowerPoint/Word?**
A: Yes! Download as PNG, SVG, or PDF and insert into your documents.

**Q: Can I share the link to this tool with others?**
A: Yes, if it's deployed on GitHub Pages. Otherwise, share the file itself.

**Q: Why isn't my chart showing?**
A: Make sure you've selected at least one column. Some text columns don't have numeric data and won't display.

**Q: Can I edit the chart after downloading?**
A: PNG and PDF - no (raster images). SVG - yes! Open SVG files in Adobe Illustrator, Inkscape, or other vector editors.
